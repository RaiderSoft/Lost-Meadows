# Demo Plan for User Testing

- Start with slow run down of the capabilities of the application:
  - Start with what the actual map is showing
  - Then explain the division of the UI (left being map and right being data)
  - Move how we can adjust opactiy and filtering out the lower quality results
  - Then move into the different map options
  - From there go into the additional layers
  - Explain how you must select a meadow in order to have the additional layers appear

- Go into user testing:
  - start with a period of exploration let them play with the app and try to navigate it on their own
  - From there if we have time guide them through a watershed
