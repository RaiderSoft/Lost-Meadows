Tools & Technologies

Powering Our Solution

CORE
PLATFORM

Google Earth Engine

Digital Elevation Model (DEM) data source (USGS 3DEP 10m) and final visualization platform. The output GeoTIFF probability raster is uploaded to GEE and displayed with a color scale with multiple threshold layers.

TauDEM

Hydrological processing suite that fills pits, computes flow direction, and calculates drainage density in 3 directions (horizontal, vertical, slope). Provides core water-flow features that define where meadows form.

Python ML Stack

Scikit-Learn · Pandas · GeoPandas · Rasterio · NumPy · Shapely · JobLib — feature engineering, RandomizedSearchCV hyperparameter tuning, model training, and chunked raster prediction.

XGBoost

Similar to Random Forests but builds trees sequentially instead of in parallel. Each new tree tries to correct previous errors.

NWI Geodatabase

National Wetland Inventory (OR & CA) — source of training labels for different types of meadows.

GitHub Pages

Static site hosting for the public project landing page and app launch point.
